TkGate in your browser

TkGate opens automatically when the Linux desktop starts. Reopen it from the
TkGate desktop launcher if you close it. Example circuits are in Desktop/Examples.
Save your work in ~/Circuits, outside the installed application resources.

This is a temporary Binder session. Download files before ending it. Open the
JupyterLab file browser in another tab using this session's URL, replacing the
trailing /desktop/ with /lab/. Find Circuits, right-click your file and select
Download. Upload existing circuits with JupyterLab's upload button, then open
them in TkGate. Keep the session URL private; share the repository's Binder launch
link instead so each visitor gets a separate session.

Print to a PostScript file. In the desktop terminal, convert for download with:
  ps2pdf "circuit.ps" "circuit.pdf"
Local physical printers are not connected to this remote desktop.

Sessions may stop after inactivity or resource limits. Files are not retained.
Full browser feature validation is pending; report reproducible failures with
an example circuit. Do not upload sensitive data to public Binder sessions.
